# 理论计算机科学导引

!!! Abstract "「大三秋冬」"

    这是我在修读浙江大学《理论计算机科学导引》课程时记录的课程笔记。授课老师为 [毛宇尘](https://person.zju.edu.cn/maoyc) 老师，参考教材为 [*Introduction to Theoretical Computer Science*](https://introtcs.org/public/index.html)。在某些部分，我参考了 Michael Sipser 的经典教材 [*Introduction to the Theory of Computation*](https://cs.brown.edu/courses/csci1810/fall-2023/resources/ch2_readings/Sipser_Introduction.to.the.Theory.of.Computation.3E.pdf)。

    此门课曾经基本与《计算理论》课程内容一致，但是今年（2025 年）开始，这门课参考教材发生变化，因此往年历年卷与笔记可能不再适用。注意这门课作业内出现的定义和定理也列入考察范围。
