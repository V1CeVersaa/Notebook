# 人工智能逻辑

!!! Info

    这是我在 2025 年春夏学期修读「人工智能逻辑」时做的复习笔记。

    这门课名义叫人工智能逻辑，实际上讲述的是数理逻辑的内容，和一些符号主义人工智能的内容强相关。本门课最后一部分内容本应该是因果推断相关的内容，但是因为时间原因没有讲完，很可惜。

    本门课难度较大，内容相对之前学的数学非常抽象。
