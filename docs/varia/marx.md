## 1. 辩证唯物主义

- 哲学基本问题：思维与存在的关系问题，分为两个：物质和精神的第一性问题、思维与存在有无同一性问题。
- 物质精神第一性问题：唯物主义认为物质第一性，唯心主义认为精神第一性。
- 思维与存在有无同一性问题：可知论认为思维存在具有同一性，世界可以被认识；不可知论认为思维存在没有同一性，世界不可以被认识，绝大多数彻底的唯心主义哲学家都反对不可知论，认为世界可以被认识，但是黑格尔认同不可知论。
- 三个历史形态：朴素唯物主义、形而上学唯物主义、现代辩证唯物主义，
- 辩证法：联系发展的观点看世界，发展的根本原因在于事物内部矛盾。
- 物质的唯一特性是**客观实在性**：存在于人的意识之外，可以为人的意识所反映，但是不以人的意识为转移。
- 运动是物质的**存在方式和根本属性**，静止是运动的特殊状态。

**答题主体（唯物论）**：物质意识、主观客观、运动静止。

- **物质和意识**：**物质决定意识**，因此要坚持一切从实际出发，实事求是；意识对物质**具有能动的反作用**，正促错阻，人可以能动的认识世界改变世界，**意识**对人的生理活动有调节和控制作用。
- **主观与客观**：**尊重客观规律是发挥主观能动性的前提**，**只有充分发挥主观能动性**，才能正确地认识和利用客观规律；正确发挥主观能动性的前提为，从实际出发，实事求是，实践是客观规律性和主观能动性统一的基础，是发挥主观能动性的基本途径，需要有一定的物质基础；
- **运动和静止**：物质的根本属性是运动，运动是绝对的、永恒的、无条件的，静止是相对的、暂时的、有条件的。

**答题主体（辩证法）**：联系发展、矛盾对立统一、量变质变、否定之否定。

- **联系发展**：事物之间是普遍联系的、事物是永恒发展的。
    - 联系是客观的、普遍的、具有多样性、有条件性的，联系具有系统性、结构性。
    - 发展本质是新事物的产生和旧事物的灭亡，一切事物都是运动、变化和发展的，发展也是前进和曲折的。
- **矛盾对立统一**：相互分离但相互联结、普遍存在但各有特点。
    - 矛盾的**斗争性和同一性**是对立统一的，不同条件下可以相互转换，因此要一分为二看问题，吸收双方的优点，共同发展；
    - 矛盾的**普遍性和特殊性**是对立统一的，要勇于承认矛盾，具体问题具体分析，因地制宜解决问题；
    - 矛盾存在主要矛盾和次要矛盾，同一个矛盾存在主要方面和次要方面，要坚持**两点论和重点论**的统一，既要把握主要矛盾，又要统筹兼顾。
- **量变质变**：
    - **量变是质变的必要准备**，**质变是量变的必然结果**；
    - 两者相互作用**相互转化**，是事物发展渐进性和飞跃性的统一；
    - 重视量的积累，在量变达到一定程度的时候，抓住时机促成质变。
- **否定之否定**：
    - 任何事物都包含肯定和否定两种因素，肯定是事物中保持其存在的因素，否定是事物促使其灭亡的因素；
    - 否定是事物发展的环节，联系新旧事物，辩证的否定是自己否定自己、自己发展自己、既克服又保留。
    - 辩证否定的实质是“**扬弃**”。
    - 揭示事物的**前进性和曲折性**的统一，形式上看是螺旋式上升或波浪式前进的，内容上看是自我发展、自我完善的过程。

**答题主体（认识论）**：实践与认识、真理与价值。

- **实践的决定性作用**：实践是认识的来源、是知识发展的动力，是认识的目的，是检验真理的唯一标准。
- **认识的本质**：认识是主体在实践基础上对客观事物的能动反映。
- **认识的过程**：从实践到认识，实践中获得**感性认识**，上升为**理性认识**，再从**认识到实践**，认识是为了更好的改造世界，同时通过实践检验与发展认识。
- **实践的特点**：直接现实性、自觉能动性、社会历史性。
- **真理**：真理是主体对客体的正确反映，具有客观性和条件性，认识具有无限性和反复性，追求真理是一个永无止境的、曲折的过程，需要在实践中认识和发现真理，在实践中检验和发展真理。
- **真理的绝对性和相对性**：真理的内容表明其主客观统一的确定性和发展的无限性；人在一定条件下对事物的客观过程与规律的认识总是有限度的，从广度上有待扩展，从深度上有待深化，从进程上有待发展。
- **价值**：价值具有主体性、客观性、多维性、社会历史性，需要我们自觉站在最广大人民的立场上，坚持把人民群众的利益作为最高价值标准，在实践的基础上进行价值判断和价值选择。

## 2. 人类社会及其发展规律

一个问题，两个规律，五大动力：

- 历史观的基本问题：社会存在和社会意识的关系；
- 两个规律：生产力和生产关系矛盾运动的规律，经济基础和上层建筑矛盾运动的规律。
- 五大动力：社会基本矛盾、阶级斗争、社会革命、改革、科学技术。

### 2.1 社会存在和社会意识的关系

- 哲学基本问题在历史观中的贯彻和表现就是历史观的基本问题。
- 唯心史观：社会意识决定社会存在；唯物史观：社会存在决定社会意识
- 社会存在：社会物质生活条件，社会实践和物质生活条件的总和，物质生活资料的生产和生产方式、地理环境和人口因素。
- 社会意识：社会生活的精神方面，社会存在的反映，属于上层建筑的社会意识形式称为社会意识形态（道德、艺术、宗教、哲学、政治法律思想）。

**答题主体**：

- 社会存在和社会意识辩证统一；
- **社会存在决定社会意识**，决定内容、形式、产生、发展，**社会意识是社会存在的反映**，并且**能动地反作用于社会存在**；
- 社会存在具有相对独立性，有自己的发展形式和规律：社会意识和社会存在发展不完全同步并且不平衡，内部各种形式相互影响且历史继承，对社会存在有能动的反作用。
- 社会意识的能动作用是通过指导人类实践活动实现的，有赖于先进文化建设。

### 2.2 生产力和生产关系矛盾运动的规律

- 这是人类社会发展基本规律，第一次科学确定生产力发展史社会进步最高标准，揭示社会主义接替资本主义的历史必然。
- 生产力是人类同自然矛盾的实际能力，是社会基本矛盾运动中最基本的动力因素，是人类社会发展和进步的最终决定力量。
- 生产力包括劳动资料、劳动对象、劳动者，还伴随着科学技术，科学技术是第一生产力。
- 生产关系是人在物质生产的过程中形成的不以人的意志而转移的客观的经济关系，社会关系中的最基本关系，生产关系所有制关系是最基本、最具有决定性的，是物质利益关系，不是主观愿望和要求。

**答题主体**：

- **生产力决定生产关系**，**生产关系对生产力有能动的反作用**。
- 生产关系对生产力的反作用归根到底还是生产力决定的，适合就促进，不适合就阻碍。
- 两者有机结合统一，**生产力是生产的物质内容**，**生产关系是生产的社会形式**。

### 2.3 经济基础和上层建筑矛盾运动的规律

**答题主体**：

- 经济基础决定上层建筑，上层建筑对经济基础有反作用。
- 上层建筑反作用的性质，取决于其所服务的经济基础的性质，归根到底取决于是否利于生产力的发展，可以影响社会性质和历史进程，但是不能决定历史发展的总趋势。
- 上层建筑一定要适应经济基础，不允许长期落后于或不适应自己的发展，也不允许脱离经济基础的发展状况和水平。
- 上层建筑既有对经济基础的依赖性，又有相对独立性，这就使得上层建筑不会完全地、绝对地使用经济基础的需要，这两个之间总会有矛盾。

### 2.4 科学技术

**答题主体**：如何促进发展、两面性。

- 科学技术主要是通过**促进人们的生产方式、生活方式和思维方式的深刻变化**推进社会发展的。
- 科学技术对社会发展的**积极作用是主要的、基本的方面**，是推动社会经济发展的强大杠杆，是先进生产力的重要标志，对生活方式产生了深刻影响，促进了思维方式的变革。
- 但是在一定条件下**可能会带来消极后果**，比如由于使用不当、对自然规律和人与自然关系认识不够、在一定的社会制度下都有可能对人类和社会产生反作用。
- 方法论：正确把握，反对霸权，关注全球问题，建立合理制度，坚持谋求福祉，树立正确观念。

### 2.5 人民群众

**答题主体**：历史主体、决定性作用、收到制约、群众观点、群众路线。

- 人民群众是历史的**主体**，在历史发展中起到**决定性作用**，是**社会物质财富、精神财富的创造者**，是**社会变革的决定力量**。
- 人民群众创造历史的活动受到一定**社会历史条件的制约**，其中经济条件是首要的、决定性的影响，政治条件对创造历史有直接影响，精神文化条件是重要条件。
- 群众观点：坚信人民群众**自己解放自己的观点**、**全心全意为人民服务的观点**、**一切向人民群众负责**的观点、**虚心向群众学习**的观点。
- 群众路线：**一切为了群众**，**一切依赖群众**，**从群众中来**，**到群众中去**。
- 杰出人物：是社会变革的**先导**，起**领导核心**的作用，有时候能决定个别历史事件的进程和解决，但是不能决定历史发展的**基本趋势**，也收到社会发展客观规律的制约。

## 3. 政治经济学

- 商品二因素：使用价值和价值，不可兼得但是同时具有。
- 劳动二重性：具体劳动和抽象劳动。
- 商品价值量：和社会必要劳动时间成正比，和劳动生产率成反比。
- 货币：价值尺度、流通手段、贮藏手段、支付手段、世界货币。
- 价值规律：商品的价值量由生产商品的社会必要劳动时间决定，商品交换以价值量为基础，实行等价交换，是自发的。
- 资本主义的基本矛盾：生产资料的资本主义私人占有和生产社会化的矛盾。
- 私有制商品经济的基本矛盾：私人劳动和社会劳动的矛盾。
- 资本主义雇佣劳动制度的形成是以劳动力称为商品为前提的。
- 劳动力的价值：本人生存必须生活资料的价值、家属生存必须生活资料的价值、教育培训费用。
- 资本主义生产过程的主要方面是价值增值过程，也就是剩余价值的生产过程。价值增值过程中，雇佣工人的劳动分为必要劳动和剩余劳动，剩余价值是雇佣工人创造的被资本家无偿占有的超过劳动力价值的那部分价值，工人应该活得报酬，但是被资本家无偿占有。
- 资本是可以带来剩余价值的价值，不变资本是以生产资料存在的资本，可变自动本是可以购买劳动力的那部分资本。
- 剩余价值率：剩余价值和可变资本的比率。
- 绝对剩余价值：延长工作日或者提高劳动强度，相对剩余价值：缩短必要劳动时间。
- 决定关系：
    - 使用价值是商品能满足人们某种需要的属性，有用性，构成社会财富的物质内容；
    - 价值是凝结在商品中的无差别的人类劳动，是商品的社会属性。
    - 抽象劳动是无差别的一般的人类劳动，是使用价值/社会财富的源泉。
    - 具体劳动是生产一定使用价值的有用劳动。
    - 社会必要劳动时间是在社会平均劳动熟练程度和劳动强度下制造某种使用价值所需要的劳动时间，决定商品价值量。
    - 劳动生产率：劳动者生产使用价值的能力。
- 经济危机本质特征：生产相对劳动人民有支付能力的需求过生。
- 经济危机的根源：生产无限扩大和劳动人民有支付能力的需求相对缩小，个别企业内部生产的有组织性和整个社会生产的无政府状态。

## 4. 资本主义的发展及其趋势

### 4.1 如何认识和把握经济全球化及其影响

- **表现**：生产、贸易、金融、企业经营。
- **原因**：科学技术进步、生产力发展、跨国公司发展、各国经济体制变革。
- **影响**：发展中国家机遇与挑战并存、可以吸收现金技术和管理经验，但是地位和收益不平衡，资源短缺、环境恶化、经济风险上升。
- **逆全球化**：资本主义国家为了维护短期利益实行的，经济发展具有历史必然性，需要坚持推动。

### 4.2 近年来资本主义社会发生了哪些变化，请分析其原因和影响

- **变化**：福利保障、提升工资、中产阶级、宏观调控；
- **原因**：根本在于可续技术和生产力发展、工人阶级争取个人权利和利益、社会主义制度初步显示优越性、改良主义政党变革。
- **实质**：人类社会发展的一般规律和资本主义经济规律作用的结果，没有改善资本主义生产关系的实质。
